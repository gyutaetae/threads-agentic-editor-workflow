AI intervention 논문에서 model accuracy만 정리하면, 실제 사용자가 무엇을 입력하고 출력을 어떻게 행동으로 바꿨는지 놓치기 쉽습니다.

내가 model 오류와 사용자 절차 오류를 구분 못하면, 그건 intervention 검토가 아니라 성능표 요약입니다.

나쁜 요청:
“이 AI 임상시험의 성능을 요약해줘.”

좋은 요청:
“AI가 받는 input과 내보내는 output을 분리해줘.”
“사용자가 받은 training과 지침을 표시해줘.”
“output이 실제 decision으로 바뀌는 단계를 써줘.”
“performance error 분석과 대응을 연결해줘.”

좋은 AI intervention 검토는 accuracy 숫자가 아니라
사람과 model 사이의 실행 경로를 설명하는 일입니다.
---
[먼저 확인할 것]
human-AI interaction을 네 칸으로 나눕니다.

1. 누가 어떤 input을 제공했는가
2. AI가 어떤 형태의 output을 냈는가
3. 사용자가 그 output으로 무엇을 했는가
4. 오류를 어떻게 발견하고 대응했는가
---
[저장해둘 프롬프트]
논문 method를 읽을 때 붙여 넣을 문장:

“AI intervention을 user, input, model output, user action, error analysis 열로 나누고 보고되지 않은 칸을 표시해줘.”
