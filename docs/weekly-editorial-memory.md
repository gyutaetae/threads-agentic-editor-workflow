## Editorial Decisions

- Main post should stop the scroll with a clear consequence, not a generic AI claim.
- Replies should feel like a continuing argument: `[핵심 한 줄]` first, then the practical point.
- Keep English academic terms only when Korean loses precision: `claim`, `evidence`, `citation`, `limitation`, `reviewer critique`.
- Rotate surfaces: failed request, paper-reading mistake, symbolic researcher image, source-backed workflow, short personal proof.
- Avoid repeating the same 4칸 names, ending sentence, or bad request.
