# Learnings

This file is loaded near the top of the generation prompt. Keep it short. Add only durable lessons that should affect future runs.

## Current Rules

- Start from a real paper-work problem, not a broad AI claim.
- Every chain needs a reusable unit: practical prompt, checklist, agent instruction, or source-to-workflow template.
- For citation posts, focus on whether a citation directly supports the claim, not only whether the reference exists.
- In automatic mode, do not claim first-person experience unless the user supplied it.
- Avoid repeating the old always-on teaching card: bad request, four good requests, bracketed replies, prompt pack, source reply.
- Use Korean for names and general prose. Keep English only for technical terms such as `claim`, `evidence`, `limitation`, `citation`, `AI agent`, `workflow`, and `prompt`.

## Avoid

- Hooks that begin with generic "AI 시대" framing.
- Famous-person quotes unless the verified quote directly matches the week's derived advice.
- Source links without `- 볼 부분:` or quote source links without `인용 원문:`.
